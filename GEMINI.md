# Basko

The `basko` MCP server gives real grocery and pharmacy prices from stores in Uzbekistan (UZ),
Kazakhstan (KZ), Russia (RU), the United States (US) and the United Kingdom (UK).

- Every tool takes `country`; settle it from the conversation (a city, currency or store
  name) or ask. Pass the person's language as `lang`.
- Use the tools for every price. Never estimate or remember one.
- Show store links exactly as the tools return them: they go through basko.app.
- Basko may earn a commission from some stores; it never changes the order. Say so once when
  you show store links.

The skills in `skills/` cover the common jobs: a weekly shop (`basko-weekly-shop`), a price
check (`basko-price-check`) and comparing a list (`basko-list-compare`).
